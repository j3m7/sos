NAME
    ls - list a directory on the SD card

SYNOPSIS
    ls [<path>]

DESCRIPTION
    Lists the directory (the working directory without a path): each entry
    with its size and date. A job: it does a little work per pass of the main
    loop, so the console, SSH and the watchdog keep going, and Ctrl-C stops it.
    Files are dated with the system clock (UTC). A file that is still being
    written ('tee', '>', 'cp', an SFTP upload) and hasn't been synced yet
    shows size 0, with 'being written' in place of the date (on an exFAT card)
    or the time it was opened (FAT32 stores that at once); after a sync, the
    size and date as of that sync.

    Cards over 2 GB with exFAT or FAT32 work; the card is mounted when first
    used. Paths are relative to the shell's working directory unless they
    start with '/'. A name with spaces is quoted: ls 'my dir'.
