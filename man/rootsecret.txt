NAME
    rootsecret - the root secret the keys protecting stored data derive from

SYNOPSIS
    rootsecret
    rootsecret forget      (console only)

DESCRIPTION
    The saved configuration and the SSH host key are sealed under keys derived
    from the board's root secret, and so is the key that unlocks the board's
    encrypted SD cards. 'rootsecret' says what state it is in and where it is:

        in OTP            with whether its page is locked for this boot
        in flash          an open board; not protected from someone who has
                          the board
        none              and why: a console-only board with none in OTP never
                          uses its flash for one
        unusable          present but damaged, or from newer firmware; kept as
                          it is

    It is stored twice; if one copy is damaged the other is used and this says
    so.

    'rootsecret forget' clears a record that can't be used, after you type
    'yes': its whole flash sector is erased and the next boot makes a new one.
    Refused while the root secret is usable, and always on a console-only
    board. A configuration and host key sealed under the old one can't be read
    again.
