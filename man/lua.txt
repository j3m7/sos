NAME
    lua - run Lua scripts on the second core

SYNOPSIS
    lua <file>
    lua -e <code>
    lua
    lua -b <file>
    lua ps
    lua stop

DESCRIPTION
    Lua 5.4 runs on core 1, so a script can compute flat out without slowing
    the console, SSH or the watchdog. 'lua <file>' runs a script from the card
    (a relative path starts at the working directory); 'lua -e <code>' runs
    the code given; 'lua' opens a prompt where each line runs as entered, in
    one state for the session (an expression's value is printed; Ctrl-C
    interrupts a line; Ctrl-D on an empty line or 'exit' leaves; Tab completes
    the name being typed, 'string.fo' to 'string.format', looking into tables
    without running any of the script's code). The output goes to the shell
    that started the script, and Ctrl-C stops it, as does ending the session.
    One script runs at a time.

    Quote the code after -e with '...': the shell takes quotes, '|' and '>'
    for itself (QUOTING in 'man intro'). So: lua -e 'print("hi")', and
    lua -e 'print(2 > 1)'. Unquoted words after -e are joined with single
    spaces (lua -e print(1 + 1) works too). A file name is one word, quoted
    if it holds spaces: lua 'my script.lua'.

    'lua -b <file>' runs a script in the background with no shell: its output
    goes to the log, a line at a time (dmesg; at most 10 lines a second, the
    rest counted as dropped), and its end is logged. 'lua ps' shows the
    running script, 'lua stop' stops it wherever it runs. If the card has
    /autorun.lua it starts in the background a few seconds after boot, except
    after a crash or watchdog reset (then start it by hand). Use 'lua ./ps' to
    run a file called ps.

    Scripts have the base, string, table, math, utf8 and coroutine libraries,
    'require' (modules from /lib and the working directory, Lua source only),
    and the 'sos' library: sos.read/write/append/list/remove/mkdir for files;
    sos.time, sos.uptime, sos.sleep, sos.log; timers sos.every/after/cancel
    (a background script keeps going while timers are left);
    sos.http.get/post/request for HTTPS (the response includes how long the
    request took); and tables about the board: sos.sensors, sos.mem,
    sos.version, sos.reset_reason, sos.glitch and sos.wifi.status. There is
    no io, os or debug. Failures return nil and a message. Each script may
    allocate up to 128 KB. Full details: docs/lua.md in the repository.
