NAME
    intro - the SOS shell: where it runs, typing a line, what is console only

DESCRIPTION
    The same shell runs on the serial console (USB, mirrored on UART0) and in
    each SSH session. 'help' lists the commands this channel may use, 'man'
    lists these pages, and 'man <topic>' shows one.

    Console only means the command is refused over SSH. Anything that changes
    the configuration or other protected state needs physical access to the
    console. A command marked "console only to change" can still show its
    value from SSH.

    Typing a line: Enter runs it, Backspace deletes, Up and Down recall the
    commands typed in this session (kept in RAM only, never answers such as
    passwords; Down past the newest gives back what you were typing). Ctrl-C
    discards the line, cancels a question (setup, wifi set, ...) or stops a
    running job (ls, cat, cp, a Lua script). Ctrl-D on an empty line logs out.
    Commands typed while a job runs are kept and run after it.

    Tab completes the command name and the subcommand words after it ('time s'
    Tab Tab lists 'sync server'; 'wifi st' Tab gives 'wifi stats '). When the
    matches agree no further the terminal beeps, and a second Tab lists them;
    words only the console takes are offered only there. Some values are
    offered too: the sensitivity after 'glitch watch|on', 'https://' after
    'http get|head|post', the key numbers after 'key del', the saved networks'
    numbers after 'wifi remove|prefer', the NTS servers after 'nts ke' and
    'time server', and those and the gateway after 'ping'.

    After a file command (ls, cd, cat, cp, mv, rm, mkdir, edit, more, lua) and
    after the '>' or '>>' of echo, Tab completes file names on the SD card
    ('cat do' Tab gives 'cat docs/', the next Tab goes on inside it); cd and
    mkdir offer directories only. Upper and lower case don't matter, as on the
    card itself (ASCII letters only); names with spaces or control characters
    aren't offered, and Tab doesn't mount the card. In a directory of more
    than 256 entries it lists what it read and says there is more.

    At the question for a Wi-Fi network's name ('wifi set', 'wifi add',
    setup), Tab completes the names of the networks around, strongest first,
    and a second Tab lists them with their signal. They come from a scan that
    starts when the question is asked and takes about half a second; until it
    ends Tab only lists what it has heard so far. Names with characters that
    can't be shown as they are aren't offered. At the chat prompt it completes
    /who, /quit and the names in the room. At the Lua prompt it completes
    names of globals and table fields ('string.fo'). Tab does nothing at a
    password or any other question.

    The console asks for its password before taking any command, once one is
    set, and locks itself again on logout, when the USB terminal disconnects
    and after 10 minutes with nothing typed; whatever it was running is ended.

    Paths given to the file commands are relative to the shell's working
    directory ('cd', 'pwd') unless they start with '/'. File names with spaces
    aren't supported yet.

    Full-screen programs: 'edit <file>' edits a file, 'more <file>' reads one
    a screen at a time, and 'man <topic>' shows a page in the same viewer.
